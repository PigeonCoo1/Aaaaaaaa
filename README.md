# Explorer Map

Find rocks, minerals, crystals, fossils, plants, animals, parks and landmarks around you — on a map you can rotate, tilt and view in 3D.

Open `index.html` (or host the folder on any static host). No build step, no account needed.

## Where the data comes from (all free, no key)

| What | Source |
|---|---|
| Mines, prospects, mineral / crystal / gem occurrences | USGS Mineral Resources Data System |
| Fossil sites | Paleobiology Database |
| Rock under any spot ("ground scan"), geologic map overlay | Macrostrat |
| Soil type, elevation | ISRIC SoilGrids, Open-Meteo |
| Caves, peaks, quarries, parks, reserves, water, history | OpenStreetMap (Overpass) |
| Named natural features and landmarks | Wikidata, Wikipedia |
| Plants, animals, fungi | iNaturalist |

Press and hold anywhere on the map (or tap 🔬) to scan the rock and soil under that spot.

## AI chat

Settings → AI models. Add your own API key for Claude (default: Claude Sonnet 5.5), ChatGPT or Gemini (default: Gemini 4 Hydrogen). Each provider's full model list is loaded live from your key. Keys stay in your browser. With no key, a built-in guide answers from Wikipedia and the map data.
